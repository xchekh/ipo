Ноутбук собирает из сырой выгрузки `Статистические ряды_регионы.xlsx` файл
`Региональные таблицы (кол-во, объем, ДДУ, характеристики).xlsx` с листами
«кол-во», «объем», «ДДУ» и «01_02_05» (характеристики кредитов) в формате таблицы Дани, с уникальными тикерами.

Файл каждый раз собирается целиком заново: выгрузка содержит всю историю с 2018 года,
поэтому в результате есть и прошлые периоды, и новые месяцы. Старый файл для сборки не нужен.

### Как обновить файл, когда вышли данные за новый период

**Один раз заранее:** получить доступ к репозиторию `xchekh/ipo` на GitHub (репозиторий приватный) —
или попросить владельца поделиться копией ноутбука через Google Drive.

**Каждое обновление:**

1. Скачайте с портала свежую выгрузку `Статистические ряды_регионы.xlsx`. Ничего в ней не меняйте —
   нужны листы `01_02_01`, `01_02_03`, `01_02_05` в исходном виде.
2. Откройте ноутбук по ссылке выше и войдите в Google-аккаунт. При первом запуске Colab попросит
   разрешить доступ к GitHub — согласитесь.
3. Выберите **Среда выполнения → Выполнить все**. Если появится предупреждение, что ноутбук создан
   не Google, нажмите **«Всё равно запустить»**.
4. Нажмите **«Выберите файлы»** и загрузите выгрузку.
5. Подождите 2–3 минуты — готовый xlsx скачается сам.
6. Проверьте вывод под кнопкой: на всех четырёх листах должно быть **«дублей: 0»**.
7. Замените старый файл новым **с тем же именем и в той же папке**, чтобы ссылки из модели продолжили работать.
8. Откройте файл в Excel и убедитесь, что модель подтягивает данные.

### Что важно знать

- **История может немного измениться.** Портал иногда пересматривает прошлые периоды задним числом —
  в новом файле будут актуальные значения источника, часть старых цифр может отличаться от предыдущей версии.
- **Ошибка «у региона … строк вместо 19»** значит, что в выгрузке изменился набор ипотечных программ.
  Формулы Дани на листе ДДУ рассчитаны на фиксированную структуру — скрипт нужно доработать.
- **Ошибка «В выгрузке нет листа …»** — загружен не тот файл или выгрузка изменила формат.
- **Новый регион** получит тикер, равный своему названию. Если модель ждёт другое написание
  (как «Город Москва» вместо «г. Москва»), добавьте его в словарь `REGION_TICKERS` в первой ячейке кода ноутбука.
- Если портал когда-нибудь начнёт отдавать выгрузку только за последний период, без истории,
  прошлые значения пропадут — в этом случае скрипт тоже нужно доработать.

### Как устроен результат

- **кол-во / объем** — программы по регионам (шт. / млн руб.), без «Все программы» и
  «Ипотека в отдельных регионах». Тикер: `<регион> <программа>`, напр. «Город Москва Льготная ипотека».
  Тикер считается формулой Дани `=$B$<строка региона>&A` — из тикера в строке региона и названия программы;
  результаты формул записаны в файл. Если поправить тикер в строке региона, тикеры его программ изменятся сами.
- **ДДУ** — «Покупка по ДДУ» по всем программам. Ключ считается формулой Дани
  `=СМЕЩ(D;-A;0)&СМЕЩ(D;-B;-1)&C`, напр. «Город МоскваВсе программы   Покупка по ДДУ, шт.»;
  результаты формул записаны в файл, поэтому ключи видны и без пересчёта в Excel.
- **01_02_05** (характеристики кредитов) — средняя сумма, ставка, ПВ, срок, стоимость, площадь, цена м².
  Лист назван и устроен как `01_02_05` у Дани: A — подписи, B — тикер региона, C — ключ, данные с колонки D,
  в строке 3 — номера колонок для ВПР. Ключ и числа стоят только в строке региона, формулами Дани:
  ключ `=B&A(+1)&A(+5)` (напр. «Город МоскваВсе программы   Средний срок кредита, мес.»),
  числа — ссылки на строку «Средний срок кредита, мес.» по всем программам. Результаты формул записаны в файл.
- **Ошибка «у региона … нет строки «Все программы» / «Средний срок кредита, мес.»»** — в выгрузке изменилась
  структура листа `01_02_05`, скрипт нужно доработать.
- Тикер региона — как у Дани; где у Дани стоял 0 или #N/A (федеральные округа, Ненецкий и Чукотский АО,
  новые регионы), используется название региона, чтобы ключи не совпадали.

### Без Colab

```
pip install openpyxl
python build_regional_tables.py "Статистические ряды_регионы.xlsx"
```

Скрипт `build_regional_tables.py` содержит тот же код, что и ноутбук. Он не трогает мастер-файл
`Статистические ряды_регионы (с таблицами).xlsx`; старый скрипт обновления мастера
`update_regional_tables.py` не знает про тикеры регионов и лист характеристик кредитов (в мастер-файле он называется «Характеристики кредитов»).
